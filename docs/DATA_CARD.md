# کارت داده — inno-medical-triage

- **منبع:** کاملاً مصنوعی؛ تولید با `python -m inno_medical_triage generate --seed N` (قطعی). هیچ داده‌ی بیمار، شخص یا مرکز واقعی در ریپو نیست.
- **نمونه‌ی ذخیره‌شده:** `data/sample/*.csv` (seed=0).
- **فرض‌ها:** سطح مرجع از همان قواعد روی مقادیر بدون نویز تولید می‌شود؛ ورودی پرستار با نویز اندازه‌گیری و خطای برآورد منابع. توافق بالا در این شرایط به معنای اعتبار بالینی نیست.
- **استفاده‌ی مجاز:** توسعه و آزمون نرم‌افزار. استفاده برای آموزش/ارزیابی مدل بالینی یا هر تصمیم واقعی مجاز نیست.
- **حریم خصوصی:** هنگام ورود داده‌ی واقعی باید بی‌نام‌سازی، مجوز اخلاق و توافق‌نامه‌ی اشتراک داده انجام شود.
