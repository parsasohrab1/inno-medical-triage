# inno-medical-triage

**تریاژ هوشمند اورژانس**

> وضعیت: **TRL 4** — نمونه‌ی آزمایشگاهی با اعتبارسنجی اجزا روی **داده‌ی مصنوعی** (بدون داده‌ی بیمار). برای ارزیابی بالینی یا میدانی آماده نیست. ← [مستندات TRL](docs/TRL.md)

## نیاز شناسایی‌شده
ازدحام و زمان انتظار طولانی در اورژانس بیمارستان‌های دانشگاهی؛ تریاژ وابسته به قضاوت فردی پرستار است.

## محصول
تریاژ پشتیبان تصمیم بر پایه ESI و پیش‌بینی ازدحام ساعتی اورژانس.

## کاربران و ذی‌نفعان
پرستار تریاژ، رئیس اورژانس، معاونت درمان دانشگاه

## قابلیت‌های هدف
- محاسبه‌ی پیشنهادی سطح ESI از علائم حیاتی و شکایت اصلی
- پیش‌بینی بار اورژانس ۱ تا ۶ ساعت آینده
- هشدار بیماران پرخطر که منتظر مانده‌اند

## داده
ورودی علائم حیاتی، شکایت اصلی، ساعت و روز مراجعه. در مراحل اولیه فقط داده‌ی مصنوعی یا بی‌نام‌شده استفاده می‌شود.

## ریسک‌ها و محدودیت‌ها
اشتباه در تریاژ می‌تواند جان بیمار را تهدید کند؛ خروجی فقط پیشنهاد است و تصمیم نهایی با پرستار.

## مسیر پیشنهادی
1. ✅ TRL 1 → 2: تعریف نیاز و معیار موفقیت (جدول معیارها در [docs/TRL.md](docs/TRL.md)).
2. ✅ TRL 3: نمونه‌ی آزمایشگاهی روی داده‌ی مصنوعی همراه با تست.
3. ✅ TRL 4: اعتبارسنجی اجزا در آزمایشگاه با تست‌های خودکار (CI روی هر push).
4. ⬜ TRL 5: اعتبارسنجی در محیط مرتبط با داده‌ی واقعی بی‌نام‌شده — نیازمندی‌ها در [docs/TRL.md](docs/TRL.md).

## یادداشت
این ریپو بخشی از مجموعه‌ی `inno-medical-*` برای دانشگاه‌های علوم پزشکی و وزارت بهداشت است. هیچ‌یک از خروجی‌ها جایگزین قضاوت بالینی نیست.

## راه‌اندازی سریع
```bash
pip install -r requirements.txt           # فقط numpy
export PYTHONPATH=src
python -m inno_medical_triage generate --out data/sample # تولید داده‌ی مصنوعی (قطعی با seed)
python -m inno_medical_triage validate                   # اجرای معیارهای TRL 4 روی ۳ seed
python -m inno_medical_triage demo
python -m unittest discover -s tests -v
```

## آنچه پیاده‌سازی شده
`suggest_level` (قواعد گردش‌کار ESI با دلیل)، هشدار انتظار بیش از حد، پیش‌بینی ورود ساعتی (۱ تا ۶ ساعت).
